# Facebook-Style Developer Portfolio Template
A responsive developer portfolio inspired by the layout patterns of a social-media profile.

## Features

- Cover photo
- Profile photo
- Intro/about section
- Skills
- Experience
- Project "posts"
- Contact section
- Responsive layout

## Built With
 - HTML
 - CSS
 - JavaScript

## Files

- `index.html` — page structure and content
- `style.css` — styling and responsive design
- `script.js` — small JavaScript interactions

## Getting started

1. Clone the repository:
    git clone https://github.com/avzatienza029/developer-portfolio.git
2. Open the project folder:
    cd developer-portfolio
3. Open index.html in your browser.
